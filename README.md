# Exit Game - Server

Ein interaktives digitales Exit-Game, bei dem Spieler durch technische Aufgaben ein beschädigtes Flugzeug retten müssen. Die Anwendung verbindet ein web-basiertes Interface mit physischen Sensoren und Aktoren für eine immersive Escape-Room-Erfahrung.

## 🔧 Technologie-Stack

- **Backend**: Python Flask + Flask-SocketIO
- **Frontend**: HTML5, CSS3, JavaScript
- **Echtzeit-Kommunikation**: WebSockets (Socket.IO)
- **IoT**: MQTT (Mosquitto), Zigbee2MQTT
- **Infrastruktur**: Docker, Docker Compose, Traefik (Reverse Proxy), dnsmasq (DNS)
